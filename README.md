# Mac 全屏消息

适用于 Apple 芯片 Mac 的菜单栏局域网消息工具。多台 Mac 安装并运行后会自动发现彼此，任意一方都可以发送文字；接收端会立即全屏显示。

## 一条命令安装或升级

在终端执行：

```bash
/bin/bash -c "$(curl -fsSL https://github.com/hbiszxm/mac-fullscreen-message/releases/latest/download/install-latest.sh)"
```

以后升级仍然执行同一条命令，脚本会下载 GitHub Releases 中的最新版并覆盖安装。

## 使用

1. 在每台 Mac 上安装 `build/全屏消息-Apple芯片-v3.3.pkg`。
2. 安装完成后程序自动在后台启动，Dock 不显示图标。
3. 首次运行时允许“本地网络”访问。
4. 点击屏幕右上角的“上班”菜单栏图标，选择“上班、吸烟、暗棋”或自定义消息。

程序无需配对，同一局域网内即可通信，不经过互联网服务器。默认启用开机自动运行，也可从菜单栏取消。

发送后只有收到对方确认才显示成功；连接异常会自动重试三次，并在菜单栏显示失败状态。

在“发送自定义消息”窗口输入内容后，可以点击“添加到快捷列表”。保存的内容会长期显示在菜单栏中，也可通过“删除快捷消息”移除。

接收方连接多个显示器时，每块显示器都会同时全屏显示消息；无需点击按钮，在任意屏幕按 ESC 会关闭全部提示。

## 重新构建

```bash
./scripts/build.sh
```

产物：

- `build/全屏消息.app`
- `build/全屏消息-Apple芯片-v3.3.pkg`
