# 全屏消息 for Mac

适用于 Apple M 芯片 Mac 的菜单栏局域网消息工具。同一局域网内的 Mac 会自动发现彼此，无需账号和配对；任意一方发送消息后，接收方的全部显示器会同时全屏显示。

## 功能

- Dock 栏不显示图标，只在顶部菜单栏后台运行。
- 默认快捷消息：上班、吸烟、暗棋。
- 支持保存和删除自定义快捷消息。
- 发送端收到对方确认后才显示成功，失败自动重试三次。
- 发送后在发送端右上角显示结果提示卡片，几秒后自动消失。
- 接收方全部显示器同时全屏显示，按 ESC 一次关闭所有屏幕。
- 全屏消息使用大号自适应文字，并带有柔和背景光效和入场动画。
- 首页集中提供消息发送、快捷列表、开机启动、在线更新和运行状态。
- 首页设置区域显示可复制的程序重启命令。
- 首页设置区域显示可复制的卸载命令。
- 首页支持向单台或所有在线电脑发送临时聊天消息，聊天不会触发全屏。
- 临时聊天带防窥模式，鼠标离开且未在键盘输入时自动遮住聊天内容。
- 收到聊天时不弹窗、不播放声音，仅在“临时聊天”旁显示闪烁未读圆点。
- 发送聊天后不弹出结果卡片，发送状态仅显示在首页。
- 顶部“上班”下拉菜单通过标准设备子菜单选择接收电脑，再直接输入并发送自定义全屏消息。
- 状态栏自定义消息可直接收藏到快捷列表；“更多”子菜单集中提供检查更新和安装、更新、重启、卸载命令。
- 状态栏第一项为“打开客户端”；自定义消息使用较窄的多行输入框，支持粘贴、复制、剪切和全选。
- 收到未读聊天时，菜单栏“上班”右侧直接显示未读数量。
- 支持应用内静默更新，下载后后台安装并自动重启，不再打开安装器窗口。
- 可从菜单中临时移除指定电脑；对方程序重启后会自动重新上线。

## 命令行安装

打开“终端”，执行：

```bash
curl -fsSL "https://github.com/hbiszxm/mac-fullscreen-message/releases/latest/download/install-latest.sh?cache=$(date +%s)" | /bin/bash
```

根据提示输入当前 Mac 的登录密码。脚本会下载最新版、覆盖旧版本并自动启动。

## 网页下载安装

1. 打开 [最新版本下载页面](https://github.com/hbiszxm/mac-fullscreen-message/releases/latest)。
2. 下载 `FullscreenMessage-AppleSilicon.pkg`。
3. 双击安装包并按提示安装。
4. 首次运行时允许访问“本地网络”。

只支持 Apple M 芯片 Mac，最低系统版本为 macOS 13。

## 打开首页

点击屏幕顶部菜单栏中的“上班”，选择第一项“打开客户端”。首页包含：

- 本机名称和在线电脑
- 自定义消息发送
- 接收电脑可选择单台或所有在线电脑
- 添加快捷消息
- 开机自动运行
- 检查更新
- 当前运行状态

## 在线更新

在顶部“上班”菜单或应用首页点击“检查更新”。程序会自动检查 GitHub 最新版本、后台安装并重新启动。

## 命令行更新

更新和首次安装使用同一条命令：

```bash
curl -fsSL "https://github.com/hbiszxm/mac-fullscreen-message/releases/latest/download/install-latest.sh?cache=$(date +%s)" | /bin/bash
```

## 命令行卸载

执行：

```bash
curl -fsSL "https://github.com/hbiszxm/mac-fullscreen-message/releases/latest/download/uninstall.sh?cache=$(date +%s)" | /bin/bash
```

卸载脚本会清理后台进程、开机启动、应用文件和本地设置。

## 手动卸载

1. 点击顶部“上班”菜单，选择“退出全屏消息”。
2. 在“应用程序”文件夹删除“全屏消息.app”。
3. 如已启用开机启动，在“系统设置 → 通用 → 登录项与扩展”中将其关闭。

## 从源码构建

需要 Xcode 命令行开发环境：

```bash
./scripts/build.sh
```

构建产物位于 `build/`：

- `全屏消息.app`
- `全屏消息-Apple芯片-v3.10.1.pkg`
