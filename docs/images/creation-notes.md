# 项目介绍图片

- `hero.png`：使用内置 imagegen 生成的品牌封面插画，参考本项目 `scripts/render-icon.swift` 绘制的应用图标。图中的设备与消息符号是示意插画。
- `menu-chat.png`、`fullscreen-alert.png`：以客户端真实 AppKit 视图及匿名演示数据渲染的功能展示图。

Pale icy blue and near-white background with a very subtle soft blue glow; dark navy typography; cobalt blue accents matching the input icon.
Left half: medium app icon above/alongside the text, large beautifully typeset Chinese title. Only the following exact text, crisp and legible:
“全屏消息”
“Mac 菜单栏消息工具”
“全屏提醒 · 临时聊天 · 未读角标”

A small elegant floating chat bubble and tiny red badge reading “3” evoke chat and unread messages. Screens are graphic illustrations, not detailed invented app screenshots. Use simple forms and realistic soft shadows, editorial product-shot quality, no desk clutter.
Keep all text clear, large, correctly spelled. Do not add any other text, claims, logos, Apple logo, version number, watermarks, gradients with banding, dense feature lists, buttons or made-up UI. Output one finished standalone banner.
